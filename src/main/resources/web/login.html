◢◤ LIGHTANALYTICS // telemetry

Sign in required

This dashboard is gated by your in-game permissions — there are no passwords to manage or leak.

  1. Join the proxy as an admin (permission lightanalytics.admin).
  2. Run /lightanalytics web in chat.
  3. Click the single-use link it sends you — it expires in seconds.

The link logs you in on this device and sets a session cookie. If you reached this page after your session expired, just request a fresh link.
